# Antigravity Crypto

以 React、TypeScript、Vite 與 Electron 製作的加密貨幣行情與模擬交易桌面應用程式。資料來源為 Binance 公開 REST API 與 WebSocket，不需要設定 API 金鑰。

## 功能

- 現貨與永續合約即時行情
- K 線圖與技術指標
- 動能雷達與市場預警
- 模擬交易、持倉與資產組合管理
- Windows 桌面版封裝

## 技術

- React 19、TypeScript、Vite 8
- Electron 42、electron-builder
- Lightweight Charts、Binance 公開 API

## 開始使用

需要安裝 Node.js（建議 LTS 版本）。

```bash
npm ci
npm run dev
```

瀏覽器版預設開啟於 `http://localhost:5173`。Windows 使用者也可雙擊 `start-fadachi.cmd`，它會在首次執行時自動安裝依賴並啟動開發伺服器。

## 即時警報

全市場成交串流直接偵測急漲跌與大額成交，畫面報價每 100ms 合併更新。預設條件為 5 秒內漲跌 1.5%，達門檻當筆立即觸發，不等待五秒窗口結束。舊版較長的窗口設定會自動遷移。

在「異動警報」開啟桌面通知與提示音，並維持程式運作。桌面版已關閉背景降頻；網路中斷、電腦休眠或作業系統通知限制仍可能延遲，不能保證比 Binance App 快。狀態列秒數為距離上次收到價格的時間，不是網路延遲。

驗證紀錄見 `artifacts/realtime/QA.md`；執行 `npm test` 可重跑警報與 K 線回歸測試。

## 急漲跌保守跟進

急漲提供做多觀察，合約急跌提供做空觀察；現貨急跌僅提示風險。警報即時發出後，依該次波動固定產生 38.2% 回撤觀察價及 25%～50% 觀察區，不隨行情移動。進入觀察區後，等待自回撤極值恢復原波動的 10%，再由新成交確認條件維持三秒。超出保守追價範圍不確認；深於 50% 回撤須回到允許範圍後重新確認。

止損／失效價設於波動起點外側原波動的 10%。確認前 TP1、TP2 為預估；確認後按確認參考價鎖定 1.5R、2R 目標與止損。這些比例未驗證勝率或獲利，價格距離百分比不是槓桿報酬率。

在異動警報的「跟進計畫」檢視狀態與點位，點選「查看 K 線」可顯示專屬圖表點位；一般交易點位線暫時隱藏，避免混用。確認、TP1、TP2 與止損觀察價觸及會各通知一次，未執行任何交易。TP1 後不自動移動止損。

等待入場最長三分鐘，確認後追蹤十五分鐘，到期不代表已平倉。單幣超過五秒未收到成交會暫停確認，恢復後重新計時；備援行情不能確認入場。同向升級不改點位，反向警報使原計畫失效。切換幣種保持追蹤，切換市場或重啟清除；最多保留五十個計畫。清除警報紀錄不停止既有計畫追蹤。

測試與限制見 `artifacts/follow-plans/QA.md`。開發模式可開啟 `/tests/fixtures/follow-plan.html` 重播成交序列；測試頁不納入桌面包或正式建置。

## 即時紙上自動交易

在「自動交易」選擇現貨或合約，確認行情與交易規格就緒後按「啟動新批次」。這是使用公開真實行情的前向模擬，不需 API 金鑰、不會送出真實訂單，也不與手動模擬帳戶共用資金。

預設每批 10,000 USDT、1 倍，單筆止損風險預算為淨值 0.5%、名目金額上限 20%，最多同時三筆，同幣一筆。現貨只做多，合約可多空。只接收啟動／恢復後的新保守確認；觀察價不是委託價。入場及退出須等待至少 250ms 後的新成交，再加預設 5 bps 不利滑價。每次成交費用假設現貨 10 bps、合約 5 bps，並非使用者的實際費率。可在開始前修改設定，進行中鎖定；警報靈敏度也在該批次期間鎖定並保存。

TP1 平原始數量的一半（依交易規格向下取整）、TP2 平剩餘；不移動止損。反向急變或持倉十五分鐘退出。跳價依退出延遲後實際觀察到的成交價計算，不假設成交於目標線。數量須符合交易規格與分批最低金額，否則留下略過／取消原因。沒有模擬訂單簿深度、市場衝擊、真實交易所接受委託或清算機制；固定滑價不能保證實際成交品質。

「暫停新進場」仍追蹤持倉；「停止接單並收尾」等待既有持倉按規則退出；「全部平倉」也必須等新成交，不用過期報價強行平倉。運行期間可換頁或選幣，但不可切換市場。串流異常持續超過五秒，或任一持倉幣種五秒無新成交，整批中斷；低成交量幣種也可能觸發此規則。中斷／重啟後不補造平倉，不繼續該批，未完成部位保留最後可靠估值並排除於完成交易勝率。

批次、成交帳本、部分退出與拒單原因保存在該瀏覽器／桌面程式的 IndexedDB，重啟保留歷史但不自動啟動。各瀏覽器、`localhost`、`127.0.0.1` 與桌面版儲存空間分開。合約按實際持有數量核對公開歷史資金費，正數支出、負數收入；每三十秒核對一次，最新六十秒保留待結算，避免把尚未公布的結算當作零成本。資金費尚未完整時不可把顯示淨值視為完整成本結果。

「完成交易」以完整平倉的一個持倉計算，TP1／TP2 不重複算兩筆勝負。可切換歷史批次、比較淨績效，匯出成交／已平倉或全批次 CSV。儲存失敗會停止評估並提示匯出。測試與限制見 `artifacts/auto-trading/QA.md`。開發重播頁為 `/tests/fixtures/auto-trading.html`；IndexedDB 重播僅允許獨立測試來源 `http://localhost:5174/tests/fixtures/auto-trading.html?storage=1`，避免合成成交混入正式測試帳戶。可另以 `npm run dev -- --host localhost --port 5174 --strictPort` 啟動測試伺服器。

## 注意事項

本專案的交易功能僅為模擬交易。市場資料來自公開端點，實際可用性取決於 Binance 在使用者所在地區的服務狀態。

### 入場觀察價與委託

布林通道點位是觀察價，不是無條件的買賣建議。做多觀察價高於現價時標示「等待收復」，做空觀察價低於現價時標示「等待跌破」，不可當成等待成交的普通限價單。目前模擬器只支援市價與回撤限價，未實作突破觸發單；可能立即成交的限價會被阻擋。

止盈、止損會依實際委託參考價檢查方向。若原有點位不適用現價，畫面會標示條件規劃並停用快捷市價跟單。送出時再次使用最新報價驗證，市價模擬成交也使用最新報價。限價跨價時以觀察到的較佳行情價模擬成交，並非真實訂單簿撮合，不保證實際成交價或獲利。

回歸測試包含 PARTI 截圖案例與做空鏡像案例，紀錄見 `artifacts/order-safety/QA.md`。
